# Security Policy

## Supported Versions

Only the latest release on the `main` branch is supported with security updates.

## Reporting a Vulnerability

As a PDF parsing and data linearization toolkit, we take file parsing safety and data privacy seriously. If you identify a security vulnerability (such as a parser exploit, remote execution vulnerability, or leak), please do **not** open a public issue.

Please report vulnerabilities privately by contacting the AllenAI security team or contacting the repository maintainers.

We will review your submission and coordinate a prompt patch release.
